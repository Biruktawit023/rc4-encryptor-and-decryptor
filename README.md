# rc4 encryptor and decryptor
This is RC4 file encryption and decryption tool written in Python.
# RC4 File Encryptor/Decryptor file.

## Description
A simple Python program that encrypts and decrypts files using the RC4 stream cipher algorithm.

## Files
encryptor.py:- Encrypts file.txt using RC4
decryptor.py:- Decrypts file.txt using RC4

## How It Works
1. Reads file.txt in binary mode
2. Encrypts/decrypts the contents using RC4
3. Saves the result back to file.txt

## Requirements
You need Python 3.x

## Usage
1. Create a file.txt with any content
2. Run: python encryptor.py for encription
3. Run: python decryptor.py for decription
